# โลโก้ธนาคาร

ไฟล์ PNG ในโฟลเดอร์นี้มาจากแพ็กเกจ npm [`thai-banks-logo`](https://github.com/casperstack/thai-banks-logo) (เวอร์ชัน 1.0.7, ใบอนุญาตของแพ็กเกจ ISC)
ใช้แสดงคู่กับชื่อธนาคารในหน้าตั้งค่า ใบเสนอราคา/ใบจอง และหน้าโอนมัดจำ เพื่อให้ลูกค้าและเจ้าของร้านจำช่องทางโอนได้ง่าย

โลโก้และเครื่องหมายการค้าเป็นของธนาคารแต่ละแห่ง ใช้เพื่อระบุธนาคารเท่านั้น ไม่ได้สื่อว่าธนาคารรับรองหรือเกี่ยวข้องกับระบบนี้
ถ้าธนาคารใดต้องการให้เปลี่ยนหรือถอดโลโก้ ให้แทนที่/ลบไฟล์ที่นี่ (ระบบจะแสดงป้ายสีพร้อมอักษรย่อแทนโดยอัตโนมัติ)

การจับคู่ไฟล์กับรหัสธนาคาร (รหัส 3 หลักของ ธปท.) อยู่ที่ตาราง `BANK_BRANDS` ใน `src/banks.ts`
`PromptPay.png` ยังไม่ได้ใช้ในหน้าจอ เก็บไว้เผื่อใช้
