# ใบเสนอราคา vs ใบจอง

ทั้งสองใช้เทมเพลตเอกสารร่วมกัน (`src/components/BookingDocument.tsx`) ขับเคลื่อนด้วย `DocType` ใน `src/documents.ts` — ข้อมูลราคา/รายการอาหาร/ยอดรวมเหมือนกันทุกจุด ต่างกันแค่บาง field ที่แสดงผล

| จุดต่าง | ใบเสนอราคา (`quotation`) | ใบจอง (`booking`) |
|---|---|---|
| จุดประสงค์ | เสนอราคาให้ลูกค้าตัดสินใจ **ก่อน**ยืนยันจอง | ยืนยันรายละเอียดงานที่ **จองแล้ว** |
| เลขที่เอกสาร | ขึ้นต้นด้วย `QT-` (เช่น `QT-2025-123`) | ใช้เลขที่จองจริง (เช่น `BK-2025-123`) |
| บรรทัดใต้เลขที่เอกสาร | "ยืนราคาถึง [วันที่]" — ยืนราคา 7 วันนับจากวันออกเอกสาร (`quotationValidUntil`) | "สถานะ [รอยืนยัน/ยืนยันแล้ว/เสร็จสิ้น/ยกเลิก]" |
| เงื่อนไขท้ายเอกสาร | เน้นเรื่องราคา มัดจำ และระยะเวลายืนราคา | เน้นขั้นตอนวันงาน (ทีมงานเข้าพื้นที่, แจ้งเปลี่ยนแปลงล่วงหน้า, นโยบายยกเลิก) |
| ราคา / รายการอาหาร / ยอดรวม | เหมือนกัน | เหมือนกัน |

สรุปสั้นๆ: **ใบเสนอราคา** = เอกสารเสนอราคาให้ลูกค้าดูก่อนตกลง (มีวันหมดอายุยืนราคา), **ใบจอง** = เอกสารยืนยันงานที่จองไปแล้วจริง (โชว์สถานะงานแทน) — อ้างอิงจาก booking เดียวกัน ต่างกันแค่ label กับเงื่อนไขที่แสดง

## อ้างอิงโค้ด

- `src/documents.ts` — กำหนด `DocType`, `DOC_LABEL`, เลขที่เอกสาร (`docNumber`), และวันหมดอายุยืนราคา (`quotationValidUntil`)
- `src/components/BookingDocument.tsx` — เทมเพลตเอกสารที่ใช้ร่วมกันทั้งสองแบบ, เลือกแสดงผลตาม `type === 'quotation'`
